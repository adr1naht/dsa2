### Problem
A hospital uses a priority queue to manage patients according to severity. A higher severity score has higher priority.

Input:
`45, 72, 30, 90, 65, 50, 85`

### Contents
- `src/assignment_q1.c` – Complete C implementation
- `input/input.txt` – Given input data
- `output/program_output.txt` – Expected execution output
- `trace/max_heap_trace.txt` – Max Heap after each insertion
- `trace/heap_sort_trace.txt` – Heap Sort intermediate states
- `trace/quick_sort_trace.txt` – Quick Sort partition trace
- `analysis/complexity_analysis.md` – Complexity and space analysis
- `analysis/comparison_table.md` – Comparison of approaches
- `conclusion.md` – Final conclusion

### Compile and run
```bash
gcc src/assignment_q1.c -o assignment_q1
./assignment_q1
```

On Windows:
```bash
gcc src/assignment_q1.c -o assignment_q1.exe
assignment_q1.exe
```
